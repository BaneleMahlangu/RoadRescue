# RoadRescue

**A web-based roadside assistance platform designed to connect stranded motorists with roadside assistance services.**

## Live Demo

[Explore RoadRescue](https://roadrescue-liard.vercel.app/)

## About the Project

RoadRescue is a web-based roadside assistance platform developed to make roadside support more accessible and convenient for motorists experiencing vehicle breakdowns and emergencies.

The platform allows motorists to request assistance, share their location, view estimated service costs and track approaching service providers.

## Features

- **Multiple Assistance Services:** Support for battery problems, flat tyres, fuel delivery, mechanical issues, towing and vehicle lockouts.
- **GPS Location Detection:** Allows motorists to share their current location and adjust their pickup point.
- **Upfront Pricing:** Provides estimated service costs in South African rand before a request is submitted.
- **Live Tracking:** Allows motorists to track service providers and receive status updates.
- **Service Provider Registration:** Provides an opportunity for roadside assistance businesses to register and access the platform.
